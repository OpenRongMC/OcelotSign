# 豹猫指示牌（OcelotSign）

简体中文 · [English](./README_EN.md)

迷上城建的交通标识扩展，提供中国大陆风格的道路标志牌、标线、立杆和可编辑的指路牌，可用于路口、高架和城市道路。

## 下载与安装

- 版本 · [v1.0.2-rongmc.1+26.3](https://github.com/OpenRongMC/OcelotSign/releases/tag/v1.0.2-rongmc.1%2B26.3) (已发布)
- 下载文件 · `rongmc-ocelotsignmod-1.0.2-rongmc.1.26.3-dev.jar`
- 运行环境 · Minecraft Java 26.3, Fabric, Java 25
- Fabric 模组 ID · `rongmc_ocelotsignmod`
- JAR 声明的依赖 · [Fabric API](https://modrinth.com/mod/fabric-api), [`rongmc_mishanguc`](https://github.com/OpenRongMC/Mishang-Urban-Construction) `>1.6.4`

把发行 JAR 放入对应实例的 `mods/` 目录。客户端与服务端同时装匹配的迷上城建和 OcelotSign。按发布清单核对 Fabric 模组 ID，尤其不要将不同发行渠道的前置混用。

## 如何验证

先在创意模式装一根立杆和一面路牌，再试编辑文字或图案、保存并重新进服检查。内置字体与网站的署名及许可见上游说明。

## 从源码开始

```sh
./gradlew tasks
```

先用 Java 25 检查当前源码树提供的任务，再选择对应的构建任务。
