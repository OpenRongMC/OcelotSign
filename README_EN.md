# OcelotSign

[简体中文](./README.md) · English

A Mishang Urban Construction addon for mainland Chinese traffic signage. It provides regulatory and direction signs, road markings, posts and editable sign panels for junctions and city roads.

## Download and installation

- Version · [v1.0.2-rongmc.1+26.3](https://github.com/OpenRongMC/OcelotSign/releases/tag/v1.0.2-rongmc.1%2B26.3) (Release)
- Release asset · `rongmc-ocelotsignmod-1.0.2-rongmc.1.26.3-dev.jar`
- Runtime · Minecraft Java 26.3, Fabric, Java 25
- Fabric mod ID · `rongmc_ocelotsignmod`
- Dependencies declared by the JAR · [Fabric API](https://modrinth.com/mod/fabric-api), [`rongmc_mishanguc`](https://github.com/OpenRongMC/Mishang-Urban-Construction) `>1.6.4`

Place the release JAR in the instance’s `mods/` directory. Install matching OcelotSign and Mishang Urban Construction builds on both sides. Check Fabric mod IDs in the release metadata, especially if mixing distribution channels.

## How to try it

First place a post and sign panel in creative mode. Edit its text or graphics, save and reconnect to check persistence. See the upstream documentation for the bundled fonts and website credits.

## Working from source

```sh
./gradlew tasks
```

Inspect the tasks available in this checkout with Java 25 before selecting a build task.
